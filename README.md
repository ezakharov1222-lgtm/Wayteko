# WAYTEKO

CRM дилерской сети Вайтек Премиум — приложение для телефона и компьютера.

Открыть: https://ezakharov1222-lgtm.github.io/Wayteko/

Данные в папке `data/` зашифрованы (AES-256-GCM, ключ из пароля через PBKDF2) и обновляются раз в сутки из интернет-версии CRM. Без пароля прочитать их нельзя.
